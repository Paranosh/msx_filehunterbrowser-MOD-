
                   Usage keys:

                   M ................. Change MSX target
                   R/D/C/V ........... Select a panel
                   TAB ............... Next panel
                   UP/DOWN ........... Select item
                   RIGHT/LEFT ........ Next/Prev page
                   Shift+RIGHT/LEFT .. Begin/End of the list
                   F2 .................... Search by text
                   F1 ................ Help
                   ENTER/F5 .......... Select / Download file
                   ESC ............... Back / Exit
                   / ................. Browse folders from root
