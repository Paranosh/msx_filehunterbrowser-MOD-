
                   Usage keys:

                   L/R/D/C ........... Select a panel
                   TAB ............... Next panel
                   M ................. Change MSX target
                   UP/DOWN ........... Select item
                   RIGHT/LEFT ........ Next/Prev page
                   Shift+RIGHT/LEFT .. Begin/End of the list
                   F1 ................ Help
                   F2 ................ Search by text
                   F5 ................ Launch SofaRun (SR.COM)
                   ENTER ............. Select / Download file
                   ESC ............... Back / Exit
                   / ................. Browse folders from root
